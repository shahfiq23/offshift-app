# Rhythm

Personal planner: IPPT 2.4 km training, Security+ (SY0-701) videos, screen time, built around the Cyber Shift roster.

Live at https://shahfiq23.github.io/offshift-app/ — installed on iPhone via Safari → Share → Add to Home Screen.
Progress is stored on the phone (use Roster → Backup to copy it out).

To update: replace `index.html`, bump `VERSION` in `sw.js`, commit. The phone picks it up next time the app opens with internet.
